# 迷你版校园信息中心

> 课堂案例复现 — 整合 Bootstrap + 原生 JS + ECharts + Three.js

## 项目简介

软件开发综合实践第八次课案例复现作品，搭建"迷你版校园公共信息与数据展示中心"骨架，包含首页导航、自习室查询、使用统计、校园三维导览四大模块。

## 运行方法

**直接双击打开**：双击 `index.html` 即可在浏览器中查看所有功能（图表数据已内嵌，支持 file:// 协议）。

**本地服务器方式**（如需测试 JSON 加载错误处理）：
```bash
cd integration
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 目录说明

```
integration/
├── index.html              # 统一入口（导航 + 自习室 + 统计）
├── css/
│   └── style.css           # 自定义样式（在 Bootstrap 之后引入）
├── js/
│   └── app.js              # 交互逻辑（筛选、图表渲染、导航高亮）
├── data/
│   └── data.json           # 数据文件（自习室信息、使用统计）
├── three-d/
│   └── scene.html          # 三维展示页（Three.js 校园场景）
└── README.md
```

## 功能模块

### 1. 首页与导航
- Bootstrap 5.3.0 固定导航栏，四个入口
- 移动端汉堡菜单折叠
- 滚动时自动高亮当前导航项
- 四个功能卡片快速入口

### 2. 自习室查询
- 按楼层筛选（1-5楼）
- 按状态筛选（开放中 / 已关闭）
- 12 间自习室数据
- 结果实时计数
- 无结果时显示友好提示
- 重置筛选按钮

### 3. 使用统计（ECharts）
- 柱状图展示 8 间自习室近 7 天使用量
- 渐变色柱体
- 数据内嵌，支持双击直接打开
- 标题、单位、数据来源完整标注
- 加载失败时显示错误提示 + 重试按钮
- 空数据、格式错误均有对应提示

### 4. 校园三维导览（Three.js）
- 8 座校园地标建筑
- 自定义轨道控制器（鼠标拖拽旋转、滚轮缩放）
- 点击建筑查看详细信息
- 加载失败时显示错误提示 + 重新加载按钮
