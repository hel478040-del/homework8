# 迷你版校园信息中心

软件开发综合实践 - 课堂作业八（第六部分：案例复现）

## 项目简介

本项目是一个迷你版校园公共信息与数据展示中心原型，整合了前七次课程所学的前端技术，包括：

- 页面结构与语义化标签（HTML5）
- 响应式布局与 Bootstrap 组件
- 原生 JavaScript 交互与事件处理
- JSON 数据加载与状态管理
- ECharts 数据可视化图表
- Three.js 三维场景展示

## 功能模块

### 1. 首页
- Bootstrap 导航栏（支持移动端折叠）
- 功能入口卡片展示
- 滚动导航高亮

### 2. 自习室查询
- 按楼层筛选（1-5楼）
- 按开放状态筛选（开放中/已关闭）
- 实时显示结果数量
- 无结果友好提示

### 3. 使用统计
- ECharts 柱状图展示各自习室使用量
- 从 JSON 文件加载数据
- 加载失败错误提示与重试功能
- 响应式图表自适应

### 4. 校园三维导览
- Three.js 三维校园场景
- 8 座校园地标建筑
- 自定义轨道控制（旋转/缩放/平移）
- 点击建筑查看地标信息
- 加载失败友好提示

## 运行方法

由于项目使用了 `fetch` API 加载 JSON 数据，建议使用本地服务器运行：

### 方法一：使用 Python 启动本地服务器
```bash
cd integration
python -m http.server 8000
```
然后在浏览器中访问 `http://localhost:8000`

### 方法二：使用 Node.js 的 http-server
```bash
cd integration
npx http-server -p 8000
```
然后在浏览器中访问 `http://localhost:8000`

### 方法三：直接双击打开
直接双击 `index.html` 也可以打开页面，但图表部分可能因为浏览器的跨域限制（file:// 协议）无法加载 JSON 数据，此时会显示错误提示。三维场景页面可正常浏览。
