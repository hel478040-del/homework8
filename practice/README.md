# 城市图书馆信息中心

> 自主实践项目 — 整合 Bootstrap + 原生 JS + ECharts + Three.js

## 项目结构

```
practice/
├── index.html              # 首页（导航栏 + 功能卡片 + 图书查询 + 借阅统计）
├── css/
│   └── style.css           # 全局样式与响应式
├── js/
│   └── app.js              # 图书筛选交互 + ECharts图表渲染
├── three-d/
│   └── scene.html          # Three.js 三维图书馆导览
└── README.md
```

## 功能模块

### 1. 首页与导航
- Bootstrap 5.3.0 固定导航栏，4 个入口
- 移动端汉堡菜单折叠
- 4 个功能卡片（图书查询、借阅统计、三维导览、新书推荐）
- 滚动高亮当前导航项

### 2. 图书查询（原生 JS 交互）
- 按分类筛选：文学 / 科技 / 历史 / 艺术 / 少儿
- 按状态筛选：在馆 / 借出
- 12 本图书数据
- 筛选即时生效，结果计数
- 无结果时显示友好提示

### 3. 借阅统计（ECharts 图表）
- 柱状图展示 5 个类别近 30 天借阅量
- 多色柱体，顶部数值标签
- 数据内嵌于 JS，支持 file:// 协议直接打开
- 图表含标题、单位、数据来源标注
- 加载失败时显示重试按钮

### 4. 三维导览（Three.js）
- 8 座图书馆建筑（主阅览室、各分类区、自习室、多功能厅、入口大厅）
- 自定义轨道控制器（鼠标拖拽旋转、滚轮缩放）
- 点击建筑显示详细信息
- 阴影、光照、树木装饰
- 加载失败时显示错误提示与重试

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Bootstrap | 5.3.0 | 响应式布局与组件 |
| 原生 JavaScript | - | 交互逻辑与筛选 |
| ECharts | 5.4.3 | 数据可视化 |
| Three.js | 0.128.0 | 三维场景渲染 |

## 响应式设计

- **桌面** (1200px+)：4 列功能卡片，完整图表
- **平板** (768px)：2 列卡片，图表自适应
- **手机** (375px)：1 列卡片，导航折叠

## 运行方式

直接双击 `index.html` 即可在浏览器中打开，所有功能均可正常使用。

## 错误处理

- 图表加载失败：显示友好提示 + 重试按钮
- 三维场景加载失败：显示错误页面 + 重新加载按钮
- 图书筛选无结果：显示"没有符合条件的图书"
