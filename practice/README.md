# 城市图书馆信息中心

> 自主实践项目 — 整合 Bootstrap + 原生 JS + ECharts + Three.js

## 项目简介

软件开发综合实践自主实践作品，主题为"城市图书馆信息中心"。整合了 Bootstrap 响应式布局、原生 JavaScript 交互、ECharts 数据可视化和 Three.js 三维展示四大模块，是期末大作业的原型项目。

## 运行方法

**直接双击打开**：双击 `index.html` 即可在浏览器中查看所有功能（图表数据已内嵌，支持 file:// 协议）。

**本地服务器方式**：
```bash
cd practice
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 目录说明

```

```

## 功能模块

### 1. 首页与导航
- Bootstrap 5.3.0 固定导航栏，4 个入口
- 移动端汉堡菜单折叠
- 4 个功能卡片（图书查询、借阅统计、三维导览、新书推荐）
- 滚动高亮当前导航项
- 跳过导航链接（可访问性）

### 2. 图书查询（原生 JS 交互）
- 按分类筛选：文学 / 科技 / 历史 / 艺术 / 少儿
- 按状态筛选：在馆 / 借出
- 12 本图书数据
- 筛选即时生效，结果计数
- 无结果时显示友好提示

### 3. 借阅统计（ECharts 图表）
- 柱状图展示 5 个类别近 30 天借阅量
- 多色柱体，顶部数值标签
- 数据内嵌于 JS，支持 file:// 协议直接打开
- 图表含标题、单位、数据来源标注
- 加载失败时显示错误提示 + 重试按钮
- 空数据、格式错误均有对应提示

### 4. 三维导览（Three.js）
- 8 座图书馆建筑（主阅览室、各分类区、自习室、多功能厅、入口大厅）
- 自定义轨道控制器（鼠标拖拽旋转、滚轮缩放）
- 点击建筑显示详细信息
- 阴影、光照、树木装饰
- 加载失败时显示错误提示与重试
